# Transaction Fee Experiment

Static clickable prototype extracted from the original HTML export. The original design is preserved; only the links between screens were updated.

The repository root contains `index.html` plus the ten linked desktop/mobile HTML screens. It has no framework, package manager, build step, or ChatGPT dependency.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload every file in this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch** and select the root of `main`.

No build step or dependencies are required. `index.html` is the entry point.

## Publish with Vercel

1. Push this folder's contents to the root of a GitHub repository.
2. Import that repository into Vercel.
3. Keep **Framework Preset** set to **Other** and leave the build command empty.
4. Deploy.
